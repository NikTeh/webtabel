Основной этап — Задача	Что для этого делаем	В каком ресурсе	Как делаем — Команды и инструкции
7.1. Смена базового URL	Переключаем сетевой мост Retrofit со старого тестового IP ноутбука на боевой домен.	VS Code (ApiService.kt / MainActivity.kt)	Найти строку инициализации Retrofit и заменить базовый URL:
.baseUrl("https://webtabel.ru")
7.2. Проверка правил R8	Убеждаемся, что файл исключений обфускации proguard-rules.pro сохранен.	VS Code (proguard-rules.pro)	Проверить наличие файла по пути android/app/proguard-rules.pro с кодом из Сообщения №054.
7.3. Компиляция защищенного APK	Запускаем финальную сборку пакета с запутанным кодом и новым именем webtabel.	VS Code (Терминал PowerShell)	Перейти в папку: cd android
Выполнить сборку: ./gradlew clean assembleDebug
7.4. Дистрибьюция на тест	Перекидываем готовый бинарник Николаю для полевого аудита ценников.	Telegram Desktop / Бот техподдержки	Взять файл app-debug.apk из папки build/outputs/apk/debug/ и перетащить мышкой Николаю в чат.
