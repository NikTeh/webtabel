
Часть 1. Сводная карта изменений сетевых путей (Что и где менять перед деплоем)

При переходе на Docker-контур с раздельными доменами вам нужно изменить сетевые адреса ровно в трех местах проекта:
┌───────────────────────────────── СЕТЕВАЯ КАРТА ПРОЕКТА ─────────────────────────────────┐
│                                                                                         │
│  1. Смартфон Pixel 4 (Android)  ──➔  https://webtabel.ru  ──➔  [ Docker Go ]    │
│                                                                                         │
│  2. Веб-Браузер (Vite / React)  ──➔  https://webtabel.com        ──➔  [ Docker Nginx ] │
│                                                                                         │
│  3. Фронтенд ➔ Бэкенд (Внутри)  ──➔  http://backend:8080/         ──➔  [ Сеть Docker ]  │
│                                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────┘

Сводная таблица файлов конфигурации путей


Путь к файлу в проекте	Текущее значение (Локальный Wi-Fi)	Новое значение (Боевой продакшн + Docker)	За что отвечает этот параметр
android/app/src/main/java/com/mg/sfa/MainActivity.kt	http://192.168.1.61:8080	https://webtabel.ru (Обратите внимание на HTTPS и домен .ru)	Направляет запросы приложения со смартфона Николая на ваш боевой сервер Go API.
web/vite.config.ts	target: 'http://localhost:8080'	target: 'http://backend:8080'	Проксирует запросы во время сборки. В Докере вместо localhost пишется системное имя контейнера бэкенда.
web/src/ReportsTab.tsx	window.open('/api/v1/...', '_blank')	window.open('https://webtabel.ru...', '_blank')	Обеспечивает прямое скачивание тяжелых бинарных Excel-файлов отчетов в браузер Владельца.
backend/.env	DATABASE_URL=postgres://...localhost...	DATABASE_URL=postgres://...IP_СУБД_TIMEWEB...	Связывает контейнер Go с удаленным изолированным кластером Managed PostgreSQL
