Часть 2. План работ в новом чате (Шаг за шагом без костылей)

Нам осталось выполнить финальную сборку проекта на сервере. План состоит из 4 строго последовательных микрошагов. Мы не перейдем к следующему, пока не завершим предыдущий.

Микрошаг №1. Чистое разворачивание кода на сервере VPS

• Что делаем: Заходим на сервер по SSH. Безопасно инициализируем Git внутри папки /app и втягиваем весь чистый код с GitHub (git fetch && git reset), сохраняя утренний файл настроек .env.

Микрошаг №2. Скачивание и привязка SSL-сертификата на сервере

• Что делаем: Скачиваем файл SSL-сертификата CA.pem от Selectel прямо на жесткий диск сервера в папку /root/.postgresql/root.crt.
• Зачем: Чтобы бэкенд Go, когда запустится внутри Docker, смог зашифровать канал связи и достучаться до базы данных Selectel.

Микрошаг №3. Сборка боевого файла настроек .env на сервере

• Что делаем: Открываем файл /app/.env на сервере и прописываем в него наши чистые, проверенные раздельные переменные:env
POSTGRESQL_HOST=62.122.219.142
POSTGRESQL_PORT=5432
POSTGRESQL_USER=Nikolay
POSTGRESQL_PASSWORD=rvPVL5ti6uQ3
POSTGRESQL_DBNAME=webtabel_db
POSTGRESQL_SSLMODE=verify-ca
POSTGRESQL_SSLROOTCERT=/root/.postgresql/root.crt
Use code with caution.

Микрошаг №4. Боевой пуск Docker Compose контура

• Что делаем: Запускаем компиляцию Go, сборку статической сборки React и автоматический подъем веб-сервера Nginx одной промышленной командой: docker compose up --build -d.
• Результат: Проверяем статус контейнеров через docker ps. Система оживает, домены начинают работать на весь мир.

Часть 3. Инструкция для Андроид-приложения (Pixel 4)

После успешного выполнения серверного деплоя, на ноутбуке останется сделать финальное действие по мобильному контуру:
1. Открыть проект в Android Studio (или VS Code).
2. Проверить, что в файлах ApiService.kt и MainActivity.kt базовый сетевой URL Retrofit переключен на боевой домен: .baseUrl("https://webtabel.ru").
3. Открыть терминал и запустить финальную промышленную сборку защищенного пакета с обфускацией кода R8:powershell
cd android
./gradlew clean assembleDebug
Use code with caution.
4. Взять готовый бинарный файл app-debug.apk из папки build/outputs/apk/debug/ и передать его на полевой аудит.
